💡 COMANDOS ÚTEIS
─────────────────────────────────────────────────────────────────────────────

  Ver status dos containers:
    docker compose ps

  Ver logs em tempo real:
    docker compose logs -f dsm-app

  Parar ambiente (mantém dados):
    docker compose stop

  Remover containers (mantém volumes):
    docker compose down

  Remover tudo (APAGA TUDO!):
    docker compose down -v

  Reconstruir imagem:
    docker compose build --no-cache

  Executar testes:
    docker compose exec -T dsm-app npm test

  Entrar no container (shell):
    docker compose exec -it dsm-app sh

❓ SOLUCIONAR PROBLEMAS
─────────────────────────────────────────────────────────────────────────────

  Porta 3000 em uso?
    Altere APP_PORT em .env, ex: APP_PORT=3001
    Acesse: http://localhost:3001

  Container não inicia?
    docker compose logs dsm-app

  Limpar cache Docker?
    docker system prune -a

  Perder dados ao remover containers?
    NÃO! Volumes Docker preservam dados.
    Use: docker compose down -v   (APENAS se quiser deletar)

  Restaurar de um backup?
    Consulte a seção de backups em DOCKER.md
